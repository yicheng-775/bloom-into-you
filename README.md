# 花开成你

🌸 基于大五人格模型的沉浸式花语人格测试网页。

## 简介

《花开成你》通过 30 道花园旅途、自然场景和人生情境的选择题，探索用户的性格特征，并以一朵最能代表其生命气质的花作为人格象征。

用户获得的不仅是一份人格报告，更是一篇关于自己的植物传记。

## 技术

- 纯 HTML/CSS/JS 单文件应用
- Canvas 雷达图
- html2canvas 海报生成
- 水彩风格 CSS 渲染
